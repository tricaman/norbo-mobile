Nouveautés de cette version :

• Rappels récurrents : répétition chaque mois ou chaque année, également tous les quelques mois. Lorsque vous marquez un rappel comme fait, le suivant est créé automatiquement.
• Détails de l'antiparasitaire : ajoutez le nom du produit et le type de traitement (interne, externe ou les deux).
• Détails du médicament : notez le nom du médicament dans les événements du carnet de santé.
• Corrections de stabilité et améliorations de l'interface.
